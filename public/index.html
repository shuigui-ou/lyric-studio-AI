演唱者歌词要适配 TA 的声音

工具条「演唱」里直接选具体歌手（如 周杰伦、王菲）即可一键填好声音条件；也可在这里自由改写或填自定义歌手。AI 写词时会据此调整音节、母音开口度与音域难度，让词更适合 TA 唱。

AI 设置（提供方）

Coding Plan 用户请注意：Base URL 必须填 https://ark.cn-beijing.volces.com/api/coding/v3，模型推荐 ark-code-latest（自动调度）或 Doubao-Seed-2.1-turbo；用普通端点或 doubao-seed-2-1-pro-260628 会报“未激活模型”。

通用 OpenAI 兼容接口：任意 OpenAI 兼容的模型服务（MiniMax / DeepSeek / OpenAI / Grok …）都填这一栏，无需改代码。填好 Base URL + API Key + 模型名即可。
示例（MiniMax M3）：Base URL https://api.minimax.io/v1、模型名 MiniMax-M3（1M 上下文，标准 Chat Completions，正文不会被思维链挤光）；Key 在对应平台获取。

API Key 仅保存在本机服务（data/ark-config.json），不上传、不出现在浏览器里。也可用环境变量 ARK_API_KEY 注入。

📊 流行实测 · 用真实热歌校准写歌规则

粘贴歌词（每行一句），选曲风，点「分析」即得文本指标。多次「记入累积」后看跨样本分布。 边界：纯文本只能测 句长/字密度/韵密度/断句率/句尾四声；BPM·切分·倒字率·音域 属音频特征，需文献支撑（见 rules.json.popEvidence）。
